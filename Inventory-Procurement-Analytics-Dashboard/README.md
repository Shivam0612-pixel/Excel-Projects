# 📊 Inventory & Procurement Analytics Dashboard

## Overview
An interactive Microsoft Excel dashboard developed to monitor Inventory and Procurement performance using Pivot Tables, Pivot Charts, Slicers, KPI Cards and GETPIVOTDATA.

## Key KPIs
- Total Inventory Value
- Total Procurement Value
- Available Stock Value
- Low Stock Value
- Warehouse Inventory Value
- Delivered Orders
- Delayed Orders

## Dashboard Features
- Category-wise Inventory Analysis
- Monthly Procurement Trend
- Top 10 Products
- Top 10 Vendors
- State-wise Inventory
- Top 10 Warehouses
- Delivery Status Distribution
- Stock Status Distribution
- Interactive Slicers

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- GETPIVOTDATA
- Slicers
- Conditional Formatting
